Definisi Formal DFA: M = (Q, Σ, δ, q₀, F)

  • Q (States): {q₀ IDLE, q₁ ATTEMPT_1, q₂ ATTEMPT_2, q₃ ATTEMPT_3, q₄ AUTHENTICATED, q₅ CARD_EJECTED, q₆ BLOCKED}
  • Σ (Alfabet Input): {insert_card, pin_valid, pin_wrong, pin_invalid_fmt, cancel, take_card}
  • q₀ (State Awal): q₀ (IDLE)
  • F (Accepting States): {q₄ (AUTHENTICATED), q₅ (CARD_EJECTED)}
  • δ (Fungsi Transisi): Pemetaan deterministik total Q × Σ → Q

Mekanisme Pencegahan Keamanan Akses

  • Anti Brute-Force (Max 3 Percobaan): Kesalahan PIN menggeser state secara bertahap q₁ → q₂ → q₃ → q₆. Penyerang tidak dapat menebak tanpa batas.
  • Trap State / Dead State (q₆ BLOCKED): Setelah masuk ke q₆, setiap simbol input ∀ x ∈ Σ hanya berputar kembali ke q₆. Akses terkunci permanen hingga verifikasi Admin Bank.
  • Validasi Format Input: Input yang bukan 6 digit angka memicu pin_invalid_fmt (self-loop) sehingga format ilegal ditolak sebelum verifikasi inti.
  • Fail-Safe Exit: Tombol cancel langsung mengarahkan sesi ke q₅ (CARD_EJECTED) agar akses tidak dibiarkan terbuka.
